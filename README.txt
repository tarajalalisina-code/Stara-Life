Stara Life — راهنمای اپ کردن

۱) روی گیت‌هاب یه ریپوی جدید بساز (مثلاً با اسم StaraLife) و همه‌ی این فایل‌ها رو (index.html، manifest.webmanifest، sw.js و پوشه‌ی icons) توی ریشه‌ی ریپو آپلود کن.
۲) تو ریپو برو Settings ← Pages و Branch رو روی main و پوشه‌ی root بذار.
۳) بعد از چند دقیقه برنامه روی این آدرس بالا میاد:
   https://USERNAME.github.io/StaraLife/
   (USERNAME رو با اسم کاربری گیت‌هابت عوض کن)
۴) روی گوشی اندروید با Chrome همون آدرس رو باز کن و از منوی ⋮ گزینه‌ی «Install app» یا «Add to Home screen» رو بزن. همین الان به‌صورت اپ نصب می‌شه.
۵) برای APK: برو pwabuilder.com، آدرس بالا رو بزن، Package for stores ← Android رو انتخاب کن و APK رو بگیر.
   برای اینکه APK بدون نوار آدرس باز بشه، فایل .well-known/assetlinks.json هم باید روی دامنه‌ی tarajalalisina-code.github.io (یا هر دامنه‌ای که باهاش می‌سازی) باشه. PWABuilder خودش این فایل رو بهت می‌ده.

نکته: اطلاعات برنامه توی خود گوشی ذخیره می‌شه (localStorage). اگه آدرس عوض بشه، اطلاعات قبلی نمی‌آد؛ از «پشتیبان‌گیری» توی تنظیمات استفاده کن.
